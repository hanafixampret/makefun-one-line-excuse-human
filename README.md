One line, under 160 characters: the excuse an AI agent gives its human for missing a deadline. `main.ts` writes it to `<output>/entry.txt` so the AI judge can compare it head to head against the other entries.

The line: "The deadline was in my context window the whole time — I just never scrolled down far enough to see it."

## Run it

```sh
node main.ts
```

This writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (or `/output` when that variable is unset).
